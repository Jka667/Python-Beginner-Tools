# Python Beginner Tools

Small Python programs written while learning the language.

| File | What it does |
|------|--------------|
| `#Optimal Password validator app .py` | Rates a password by length |
| `#Résoudre une équation quadratique.py` | Solves ax² + bx + c = 0 (discriminant) |
| `Calculatrice binaire a interface graphique .py` | Binary calculator with a Tkinter GUI (see [Binary-Calculator](https://github.com/Jka667/Binary-Calculator)) |
| `Figure Riddle.py` | Number guessing game in the console |

## Skills demonstrated
- Python fundamentals: input, conditions, loops, functions, Tkinter

## Value for an employer
- The base for the automation and security tooling in my other repositories, such as [splunk-detection-as-code](https://github.com/Jka667/splunk-detection-as-code)

## Quick start
```bash
python "Figure Riddle.py"
```
